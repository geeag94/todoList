# 할 일 목록 관리 웹 앱 요구사항

## 프로젝트 개요
간단한 할 일 목록(To-Do List) 관리 웹 애플리케이션 개발

## 기능 요구사항
- [ ] 할 일 추가 (텍스트 입력 + Enter 또는 버튼 클릭)
- [ ] 할 일 완료/미완료 토글
- [ ] 할 일 삭제
- [ ] 필터링 (전체/진행 중/완료)
- [ ] LocalStorage를 사용한 데이터 영속성
- [ ] 반응형 디자인 (모바일/데스크톱 지원)

## 기술 스택
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **데이터 저장**: LocalStorage
- **빌드 도구**: 없음 (순수 HTML/CSS/JS)

## UI/UX 요구사항
- 깔끔하고 직관적인 인터페이스
- 할 일 입력 후 자동으로 입력창 초기화
- 완료된 항목은 시각적으로 구분 (취소선, 투명도)
- 할 일 개수 표시
- 빈 상태일 때 안내 메시지 표시
